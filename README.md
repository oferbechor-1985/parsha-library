# ספריית הפרשות

אתר שמותקן בטלפון כמו אפליקציה. מתחיל ריק, ובכל שבוע ביום שתגדיר נוסף אליו פירוש חדש לפרשת השבוע. אחרי כשנה הספרייה מלאה ואפשר להפסיק לייצר.

לכל פרשה יש שתי שכבות:
- **סיכום קצר** (כ-10% מאורך הפרשה, עם הומור מכבד). ביטויים בתוכו הם קישורים.
- **העמקה** (כ-30% מהאורך): הרחבה מחולקת לנושאים, עם טווחי פסוקים ומידע מעבר לכתוב. לחיצה על ביטוי מקושר בסיכום הקצר פותחת את ההעמקה וגוללת ישר לנושא הרלוונטי (למשל שכם).

## איך זה עובד

- ב-GitHub Actions רץ סקריפט פעם ביום, ופועל רק ביום הפרסום.
- הוא שולף את הפרשה המלאה מספריא, מבקש מ-Claude קודם את ההעמקה ואחר כך את הסיכום הקצר המקושר אליה, ושומר ב-`site/parshiot.json`.
- האתר (`site/`) מתפרסם ב-GitHub Pages וקורא את הקובץ הזה.

## התקנה (פעם אחת)

1. **Repository ציבורי** ב-GitHub (Pages חינמי דורש repo ציבורי. האתר והפירושים יהיו נגישים לכל מי שיש לו את הקישור, ומפתח ה-API נשאר סודי).
2. חלץ את ה-zip והעלה את כל התוכן ל-repo, כולל התיקייה הנסתרת `.github`.
3. **Settings ← Pages ← Source: GitHub Actions**.
4. **Settings ← Secrets and variables ← Actions** ← New repository secret בשם `ANTHROPIC_API_KEY` (המפתח מ-console.anthropic.com; חיוב נפרד ממנוי Claude, כשתי קריאות בשבוע, אגורות עד עשרות אגורות).
5. **Actions ← Publish weekly parsha ← Run workflow**. זה מפרסם את הפירוש הראשון ומעלה את האתר.
6. כתובת האתר מופיעה בריצה ובהגדרות Pages. פתח אותה בכרום בטלפון ← תפריט ← "הוספה למסך הבית".

## הגדרות (`config.json`, אפשר לערוך באתר GitHub)

- `publish_day`: יום הפרסום באנגלית, למשל `"Friday"`.
- `publish_hour`: שעת הפרסום המוקדמת ביותר בשעון ישראל (`11` = 11:00). GitHub עלול לעכב ריצה מתוזמנת בכמה דקות.
- `diaspora`: `true` לחוץ לארץ.
- `summary_ratio`: אורך הסיכום הקצר באחוז מהפרשה (`0.10` = 10%).
- `deep_ratio`: אורך ההעמקה באחוז מהפרשה (`0.30` = 30%).

## תחזוקה

- **פירוש שלא יצא טוב**: מחק את הפרשה מ-`site/parshiot.json` והרץ את ה-workflow ידנית (באותו שבוע בלבד).
- **להפסיק אחרי שנה**: Actions ← Publish weekly parsha ← ⋯ ← Disable workflow. האתר ממשיך לעבוד כרגיל.
- פרשות כפולות (למשל ויקהל-פקודי) ממלאות שני מקומות ברשימה. שבתות מיוחדות עלולות להשאיר מקום ריק, ואפשר להשלים אותו ידנית.
- ההעמקה נכתבת על ידי Claude ומתבססת על הטקסט. הוא מונחה לציין פרשן רק כשהוא בטוח, אבל כדאי לעבור על ציטוטים ושמות לפני שמסתמכים עליהם.
